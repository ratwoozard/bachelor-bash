# Kvalitetssikring og skriveguide

## DEL 1: Akademisk skrivestil

### 1.1 Sprog og tone

| Gør | Gør ikke |
|-----|----------|
| "Undersøgelsen viser at..." | "Vi fandt ud af at..." |
| "Det vurderes at..." | "Vi synes at..." |
| "Informanterne beskriver..." | "Folk siger..." |
| "Data indikerer..." | "Tallene beviser..." |
| "Analysen peger på..." | "Det er tydeligt at..." |
| "Der argumenteres for..." | "Vi mener at..." |

Akademisk distance betyder, at påstande begrundes med empiri og teori — ikke at teksten skal være unaturlig.

### 1.2 Kildehenvisninger

**Første gang:** Forfatter (år) i løbende tekst.  
**Efterfølgende:** (Forfatter, år). Sidetal ved citat og præcise udsagn, når siden er slået op.

### 1.3 Afsnitssandwich (analyse)

1. Påstand  
2. Teori  
3. Empiri  
4. Fortolkning  
5. Delkonklusion koblet til PF/USP  

### 1.4 Citater

Korte citater i anførsel med interview-id og linje. Lange citater indrykket. Parafrase med kilde. Ingen citater uden fil i `context/interviews/` eller bilag.

## DEL 2: Kapitelretning

### 2.1 Indledning

Omvendt trekant. Start i jeres felt. PF som HV-spørgsmål. Eksplicit afgrænsning. Læsevejledning.

### 2.2 Metode

Ontologi → epistemologi → design → empiri → operationalisering → analysestrategi → kvalitet → bias → etik.

Hvert valg: valg + begrundelse + begrænsning. Ikke pensumreferat.

### 2.3 Teori

Få teorier i dybden. Hver skal arbejde i kapitel 4. Afslut med analytisk ramme.

### 2.4 Analyse

Ét underafsnit per underspørgsmål. Triangulering. Teori i brødteksten. Ikke ren deskription.

### 2.5 Diskussion

Fund → teori → begrænsninger → implikationer. 12-talsniveau problematiserer egne fund.

### 2.6 Konklusion

Svar på USP, derefter PF. Ingen ny empiri eller teori.

## DEL 3: Hyppige fejl

| Fejl | Retning |
|------|---------|
| PF for bred | Snævr i `PROJECT.md` |
| Metode som pensumreferat | Kun jeres valg |
| Teori uden analysebrug | Fjern eller brug |
| Deskription uden fortolkning | Sandwich |
| Ingen triangulering | To kilder eller sænk claim |
| Kausal overclaim | "påvirker/indikerer" |
| Ingen bias-refleksion | Kap. 2 + ved positive case-påstande |
| Nyt i konklusionen | Flyt til 4/5 |
| Ingen rød tråd | USP i start/slut af analyseafsnit |
| For mange teorier | Færre, brugt |
