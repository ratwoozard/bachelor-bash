# FORBUDTE_FORMULERINGER

Eliminér vaghed, overclaim og metodisk uklart sprog.

## A) Forbudt → brug i stedet

| Forbudt | Brug i stedet |
|---------|----------------|
| "Dette beviser at..." | "Dette indikerer at..." |
| "X forbedrer altid..." | "X kan påvirke ... under disse forudsætninger..." |
| "Det gælder for alle virksomheder..." | "I denne case observeres ..., hvilket analytisk kan nuancere teori..." |
| "Vi valgte pragmatisme fordi den er bred." | "Vi valgte pragmatisme fordi PF kræver både [måling/fortolkning — konkretisér]." |
| "Vi laver mixed methods fordi vi har tal og citater." | "Vi anvender metodepluralisme med tydelig rollefordeling mellem datakilder." |
| "Informanten viser at..." | "Informanten beskriver at..." |
| "Tallene taler for sig selv." | "Data må fortolkes i kontekst med tydelige definitioner." |
| "Systemet er objektivt." | "Systemets data kan anvendes som evidens under dokumenterede antagelser." |

## B) Metodeafsnit

- Metode uden operationel beskrivelse.
- Tier 3 som om det var Tier 1-metodefundament.
- Begrænsninger udeladt ved centrale valg.

## C) Analyseafsnit

- Enkeltkilde-konklusioner på hovedfund.
- Kausal konklusion uden evidenskæde.
- Figur som evidens uden forklarende tekst.

## D) Før I låser et afsnit

1. Indeholder teksten "beviser", "altid", "alle", "sikkert"?
2. Er der skel mellem data, fortolkning og implikation?
3. Har hovedpåstanden mindst to kilder?
