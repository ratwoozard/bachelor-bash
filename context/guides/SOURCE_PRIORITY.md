# Source Priority — pensum og kilder

Bindende prioritering. Domæneteori står i `PROJECT.md`, ikke her.

## Tier 1 — metode og videnskabsteori (brug først)

Default for KEA Bachelor Økonomi & IT. Ret tabellen, hvis jeres uddannelse har andet pensum.

| Kilde | Primær brug |
|-------|-------------|
| **Holm (2023)** | Videnskabsteori, casestudie, anvendt forskning, kongruens |
| **Kuada (2012)** | Projektlogik, korte begrebsdefinitioner, kvalitetskriterier — ikke bærende pragmatismestrategi |
| **Saunders et al. (2023)** | Forskningsdesign, dataindsamling, sampling, forskningsfilosofi |
| **Rossman & Wilson (1984)** | Pragmatismestrategi og triangulering, *hvis* I kombinerer kval/kvant |

**Regel:** Hvis Tier 1 dækker pointen, start her. Tier 3 må ikke erstatte Tier 1 i metode/videnskabsteori.

## Tier 2 — jeres kap. 3-teorier

Det I registrerer i `PROJECT.md` og `system/THEORY_REGISTRY.md` (fx Lean, DSS, TOE — eller noget helt andet).

Brug til analysekategorier. Ikke som metodefundament.

## Tier 3 — klassikere og kontekst

Kuhn, Gergen, Gadamer, Popper, Denzin, Creswell m.fl. — nuancering.

Branche- og policydokumenter (McKinsey, EU-forordninger, OECD): problemfelt og kontekst, ikke metodefundament. Altid forfatter+år.

## Projektregler (udfylde i PROJECT.md)

- **Casestudie:** Holm/Kuada/Saunders som default. Yin kun hvis Yin er jeres pensum.
- **KPI/KQI eller andre målebegreber:** skeln effektivitet og kvalitet, hvis I bruger dem.
- **Ingen opfundne kilder eller sidetal.**
