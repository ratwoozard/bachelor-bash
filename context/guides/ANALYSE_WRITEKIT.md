# Analyse writekit — kapitel 4–6

Pragmatisk skrivedisciplin. Ved konflikt om kapitel 4 vinder `system/*`.

## Afsnitslogik

1. **Observation** — hvad viser data/artefakt/interview? (kilde)
2. **Fortolkning** — hvilken *registreret* teori forklarer mønsteret?
3. **Triangulering** — mindst én anden empirikilde eller en eksplicit modsigelse
4. **Mini-delkonklusion** — betydning for USP/PF uden kausal overclaim

## Skabelon (tilpas til jeres USP)

Kopiér ikke Lean/DSS/TOE ind, medmindre de står i `PROJECT.md`.

- **Observation:** `[kilde + hvad den viser]`
- **Teori:** `[navn + funktion]`
- **Triangulering:** `[anden kilde / spænd]`
- **Delkonklusion:** `[scoped]`

## Forbudt i analyse

Se `FORBUDTE_FORMULERINGER.md`. Kort: beviser, forbedrer, altid, alle virksomheder, enkeltkilde-hovedfund, figur uden tekst.

**Tilladt:** indikerer, kan påvirke, associeres med, tyder på, i denne case observeres

## Mini-check pr. hovedfund

- [ ] Mindst 2 empirikilder?
- [ ] Teori navngivet og registreret i `THEORY_REGISTRY.md`?
- [ ] Skel mellem måling og vurdering, hvis I bruger KPI/KQI eller tilsvarende?
- [ ] Insider-bias nævnt ved positive påstande om egen organisation?
- [ ] Scope fra `PROJECT.md` respekteret?
- [ ] Tal traceable til `research/data/` eller bilag?
