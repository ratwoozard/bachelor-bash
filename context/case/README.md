# Jeres caseviden

Læg noter, procesbeskrivelser og artefakt-uddrag **her** — ikke i `PROJECT.md`, hvis indholdet er fortroligt.

Denne mappe er tom med vilje. Skabelonen indeholder ingen andres virksomhed.

## Før I skriver

1. Afgræns casen i `PROJECT.md` (organisation vs. proces vs. artefakt).
2. Skriv kun det, I må dele, hvis repoet er offentligt. Ellers: privat fork.
3. Registrér kilder i `context/evidence/EMPIRI_STATUS.md`.

## Foreslået filnavne

- `CASE_SCOPE.md` — organisation, enhed, procesgrænse
- `PROCESS.md` — as-is trin (uden opdigtede tal)
- `ARTEFAKT.md` — hvad systemet/dokumentet gør i processen
