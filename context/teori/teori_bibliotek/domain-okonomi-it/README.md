# Domæneeksempler (Økonomi & IT)

Disse kort er **ikke** default-teori. Brug dem kun hvis de står i `PROJECT.md` og `system/THEORY_REGISTRY.md`.

Hvis jeres PF handler om noget andet (marked, organisation, økonomi uden proces-IT): slet mappen eller ignorer den. Agenten må ikke trække Lean/DSS/TOE ind automatisk.

| Kort | Typisk kilde | Funktion |
|------|--------------|----------|
| lean-waste | Womack & Jones (2003) | Spildkategorier på procesniveau |
| davenport-as-is-to-be | Davenport (1993) | Proceskortlægning og gap |
| toe-framework | Tornatzky & Fleischer (1990) | Adoptions-/implementeringsforudsætninger |
| dss-human-in-the-loop | Laudon & Laudon; Shneiderman | Beslutningsstøtte vs. menneskelig kontrol |
