# context/

Understøttende viden. Aktiv rapporttekst ligger i `report/`.

| Mappe | Indhold |
|-------|---------|
| `teori/` | Videnskabsteori, metodekort, valgfri IT-domæneeksempler |
| `guides/` | Skrivning, kildeprioritet, forbudte formuleringer |
| `evidence/` | Hvad I faktisk har (skabeloner) |
| `case/` | Jeres case — tom ved start |
| `interviews/` | Kodede uddrag — ikke offentlige transskriptioner |
| `feedback/` | Vejleder-checkliste |
