# AGENTS.md

Instruktion til AI-agenter i dette repo. Mennesker: se [GUIDE_STUDERENDE.md](GUIDE_STUDERENDE.md).

## 1. Læs først

1. `PROJECT.md`
2. `report/STATUS.md`
3. Det kapitel, brugeren peger på
4. `context/evidence/EMPIRI_STATUS.md` før tal og citater

Hvis `PROJECT.md` har tomme `[...]`: spørg eller stop. Udfyld ikke en opdigtet case.

## 2. Autoritet

1. `report/` (aktiv tekst)
2. `PROJECT.md` (PF, scope, teorier, datakilder)
3. `system/` (evidenskæde, gates, registry)
4. `context/evidence/`
5. `context/teori/` og `context/guides/`

Ved kapitel 4 vinder `system/*` over `ANALYSE_WRITEKIT.md`.

## 3. Empiri

Ingen empiri uden fil eller række i `EMPIRI_STATUS.md`. Tom tabel = findes ikke. Opfind ikke interviews, JSON, SQL eller sidetal.

## 4. Teori

Kun rækker i `system/THEORY_REGISTRY.md`. Antag ikke Lean, DSS, HITL, TOE eller andre domænemodeller.

## 5. Outputkontrakt

Hvert substanssvar:

1. Påstand
2. Teori/kilde (forfatter + år)
3. Evidenslogik (hvilken fil)
4. Begrænsning
5. Hvad censor kan angribe

Sprog: `context/guides/FORBUDTE_FORMULERINGER.md`.

## 6. Scope

Skriv kun i det kapitel, eleven peger på, medmindre de eksplicit beder om andet. Omskriv ikke kap. 1–3 "for sammenhæng" uden ordre.

## 7. Modes

- Metode: `.cursor/rules/bachelor-metode-mode.mdc`
- Analyse: `.cursor/rules/bachelor-analyse-mode.mdc`
- Kerne (altid): `.cursor/rules/bachelor-core.mdc`

JA-regler er valgfrie og slået fra.

Hurtig start: [docs/AGENT_QUICKSTART.md](docs/AGENT_QUICKSTART.md).
