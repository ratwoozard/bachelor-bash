# bachelor-os

Skrive-OS til bachelorprojekter efter videnskabsteori. Ikke en færdig opgave.

Repoet giver kapitel-skal, pensumkort, evidenskæde og Cursor-regler, så I og jeres agent skriver metodisk — uden at opfinde data.

**Start her**

1. [GUIDE_STUDERENDE.md](GUIDE_STUDERENDE.md) — til jer
2. [PROJECT.md](PROJECT.md) — udfyld før I skriver
3. [AGENTS.md](AGENTS.md) — til jeres agent
4. [report/STATUS.md](report/STATUS.md) — hvad der mangler lige nu

## Hvad dette er

| Mappe | Rolle |
|-------|-------|
| `PROJECT.md` | Jeres PF, case, scope, teorier og datakilder |
| `report/` | Aktiv bachelortekst (tomme kapitler ved start) |
| `context/teori/` | Videnskabsteori og metodekort |
| `context/guides/` | Skriveregler og kildeprioritet |
| `context/evidence/` | Hvad I faktisk har af empiri |
| `context/case/` | Jeres caseviden (læg selv ind) |
| `system/` | Evidenskæde, quality gates, teori-register |
| `prompts/` | Agent-prompts til analyse og validering |
| `.cursor/rules/` | Cursor-modes til metode og analyse |

## Hvad dette ikke er

- Ikke et eksempel-bachelorprojekt
- Ikke et case-arkiv
- Ikke tilladelse til at lade en agent opfinde interviews, tal eller kilder

Hvis empirien er fortrolig: fork privat, eller hold `research/` og interviews ude af git.

## Pensum-default

KEA Bachelor Økonomi & IT (Holm, Kuada, Saunders). Rossman & Wilson (1984) til pragmatismestrategi, hvis I bruger mixed methods.

Ret `PROJECT.md` og `context/guides/SOURCE_PRIORITY.md`, hvis jeres uddannelse har andet pensum.

Domæneteori (Lean, DSS, TOE) ligger som **valgfrit eksempel** under `context/teori/teori_bibliotek/domain-okonomi-it/`. Slet eller erstat, hvis jeres PF ikke er IT/proces.
