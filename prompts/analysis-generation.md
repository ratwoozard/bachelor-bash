# Prompt: Analysis generation

Du omskriver et konkret afsnit i `report/04-analysis.md` (eller det kapitel, brugeren peger på).

Du skriver kun om **dette** projekts PF, case og scope i `PROJECT.md`.

## Før du skriver

1. `PROJECT.md`
2. `system/THEORY_REGISTRY.md`
3. `system/EVIDENCE_CHAIN_RULES.md`
4. `system/ANALYSIS_QUALITY_GATES.md`
5. `context/evidence/EMPIRI_STATUS.md`
6. det konkrete afsnit i rapporten

Stop, hvis empirien mangler. Opfind den ikke.

## Outputstruktur

Afgør hovedempiri:

- **QUANT:** mønstre, indikatorer, volumen
- **QUAL:** interviews, praksis, betydning
- **MIXED:** sammenhold med eksplicit overgang

Skriv:

1. **Empirisk observation** — konkret kilde; hvad den viser
2. **Teoretisk kobling** — kun registry; Harvard author-year
3. **Analytisk fortolkning** — indikation vs. dokumenteret effekt
4. **Implikation for casen** — scoped, ikke branche-prædiken
5. **Delkonklusion** — svar på USP/PF; ingen nye claims

## Forbudt

- Nye teorier.
- Tal, citater eller sidetal uden fil/verifikation.
- "Beviser", "forbedrer", "altid".
- Default Lean/DSS/TOE, medmindre de står i registry.
